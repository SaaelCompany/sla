# Portal SLA для Jira Service Management 4.21.1

Плагин показывает SLA на портале клиента и даёт визуальный конструктор: где стоит блок, как он выглядит и какие метрики в него входят. Страница конструктора собрана из того же отрисовщика, что и портал, поэтому правка в редакторе совпадает с тем, что увидит клиент.

Нужны Jira 8.21.x и Jira Service Management 4.21.1. Байткод плагина — Java 8 (`major` 52): на более новом JDK он собирается, но Jira 8.21 не загрузит класс новее 1.8.

## Сборка

JDK 8 или новее и Maven 3.6+.

```bash
mvn -B package
```

Готовый jar: `target/portal-sla-1.0.1.jar`. Установка: Администрирование → Приложения → Загрузить приложение.

`mvn package` гоняет тесты формата времени и схемы, а также проверяет, что классы проекта собраны в Java 8. Animal Sniffer дополнительно не даёт вызвать API новее JDK 8.

## Как включить

Ничего настраивать не нужно: если для проекта ещё не сохранены настройки плагина, в заявке клиента автоматически появляется компактный список SLA в боковой панели. Он показывает только метрики, отмеченные в Jira как **Показывать на портале клиентов**. Формат совпадает с примером на скриншоте: заголовок «SLA», оставшееся время крупнейшей единицей (`1 д.`, `2 д.`) и значок паузы.

Конструктор в параметрах проекта → **SLA на портале** необязателен. Откройте его только если нужно изменить блок. Если сохранённую раскладку выключить, клиентский блок не показывается.

Длительность дня берётся из учёта времени Jira (обычно 8 часов = 1 день). Внизу конструктора можно задать свои часы в дне и дни в неделе: для календаря 24/7 поставьте 24.

## Варианты

| Вариант | Что видит клиент |
| --- | --- |
| Компактный список | Заголовок, время и значок паузы |
| Плашки | Цветные статусы: в срок, пауза, скоро нарушит, нарушено, выполнено |
| Прогресс | Полоса прошедшего времени относительно цели |
| Обратный отсчёт | Крупный остаток, тикает, пока SLA идёт внутри календаря |
| Карточки | Цель, прошло, осталось, срок |
| Хронология | Текущий и завершённые циклы |
| Строка статуса | Статус заявки и SLA в одну линию |

Места на странице заявки: шапка, под заголовком, рядом со статусом, над описанием, над перепиской, верх и низ боковой панели, официальная панель `servicedesk.portal.request.panels`, подвал, список «Мои заявки» и свой CSS-селектор.

Если вёрстка портала отличается от ожидаемой, блок всё равно попадает в официальную панель портала. В разделе «День, неделя и свои селекторы» можно прописать селекторы вручную, по одному в строке.

## Какие SLA видны клиенту

По умолчанию блок берёт метрики с флажком **Показывать на портале клиентов** в настройках SLA. В конструкторе можно выбрать конкретные метрики или все SLA проекта. Внутренние метрики не отдаются клиенту, пока администратор проекта явно их не включит.

Клиент получает данные только по заявке, которую он и так открывает на портале. Чужие ключи отвечают так же, как отсутствующие.

На списке «Мои заявки» компактный блок ставится рядом со ссылкой на заявку, если для проекта включена зона «Список „Мои заявки“».

## Локальный просмотр конструктора

Без Jira можно открыть тот же редактор:

```bash
python3 -m http.server 8765
```

Страница: `http://127.0.0.1:8765/preview/`. Сохранение в этом режиме пишет раскладку в `localStorage` браузера и не обращается к Jira.
