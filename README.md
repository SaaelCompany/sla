# Portal SLA для Jira Service Management 4.21.1

Плагин показывает SLA внизу боковой панели заявки на портале клиента. Расположение фиксированное: блок всегда стоит в зоне «Боковая панель снизу». Конструктора расположения нет.

Нужны Jira 8.21.x и Jira Service Management 4.21.1. Байткод плагина — Java 8 (`major` 52): на более новом JDK он собирается, но Jira 8.21 не загрузит класс новее 1.8.

## Сборка

JDK 8 или новее и Maven 3.6+.

```bash
mvn -B package
```

Готовый jar: `target/portal-sla-1.0.2.jar`. Установка: Администрирование → Приложения → Загрузить приложение.

`mvn package` гоняет тесты формата времени и схемы, а также проверяет, что классы проекта собраны в Java 8.

## Что видит клиент

Настраивать ничего не нужно. В заявке, внизу боковой панели, появляются только метрики с флажком **Показывать на портале клиентов**.

Блок выглядит как панель SLA в Jira Service Management: имя метрики, значок состояния и подпись.

| Состояние | Подпись |
| --- | --- |
| Идёт и укладывается в срок | В срок |
| На паузе | На паузе |
| Срок близко | Срок близко |
| Срок прошёл | Срок прошёл |
| Уложились | В срок |
| Не уложились | Не успели |

У идущего SLA под подписью — оставшееся время и дата, например «3 д. — 15 октября, 20:00». У выполненного в срок SLA остаётся галочка и слова «В срок». Слов «Сейчас» и «Статус» нет.

Длительность дня берётся из учёта времени Jira (обычно 8 часов = 1 день).

Клиент получает данные только по заявке, которую он и так открывает на портале. Чужие ключи отвечают так же, как отсутствующие.

Если вёрстка портала не содержит боковую панель, блок попадает в официальную панель заявки `servicedesk.portal.request.panels`.
