# Виджет сервис-деска и локальный рабочий стол

Программа для обычного пользователя Windows. Права администратора не нужны: она ставится в профиль, пишет только в `HKCU` и запускается из автозагрузки этого пользователя.

На рабочем столе появляется карточка. На ней две кнопки:

- **Заявка** — написать обращение в сервис-деск компании.
- **Новости** — прочитать новости и сообщения о технических работах.

Тот же значок есть у часов. Новые новости и технические работы всплывают уведомлением. Пока общая сетевая папка рабочего стола открывается, программа копирует ярлыки на диск компьютера. Когда папка перестаёт отвечать, рабочий стол сам переключается на эту копию и возвращается на сеть, когда папка снова открывается.

## Установка

На компьютере пользователя откройте эту папку и запустите `Install.bat`.

Установщик копирует файлы в `%LOCALAPPDATA%\DesktopFailover`, добавляет запуск при входе и сразу стартует программу. Если в реестре рабочий стол уже указывает на путь `\\сервер\папка`, этот путь записывается в конфиг.

Для всех пользователей удобно один раз вызвать установщик сценарием входа:

```bat
powershell.exe -NoProfile -ExecutionPolicy Bypass -File \\server\share\DesktopFailover\Install-DesktopFailover.ps1
```

Повторный запуск обновляет файлы и не затирает уже созданный `config.json`.

## Если путь не определился сам

Откройте `%LOCALAPPDATA%\DesktopFailover\config.json` и укажите общую папку:

```json
"networkDesktop": "\\\\server\\Common\\Desktop"
```

Пустая строка означает: взять UNC-путь из реестра (`User Shell Folders\Desktop`). Так бывает при перенаправлении папок групповой политикой.

Локальная копия по умолчанию лежит в `%LOCALAPPDATA%\OfflineDesktop`. Это отдельная папка на диске компьютера, а не профиль на сервере.

## Виджет, заявки и новости

Карточка стоит в правом нижнем углу рабочего стола. Правый щелчок по ней или по значку у часов открывает те же действия. Пункт «Выход» останавливает программу до следующего входа.

Заявка уходит в Jira Service Management от имени текущего пользователя Windows. Пароль программа не хранит. Если Jira принимает вход Windows, заполните в `config.json`:

```json
"widget": {
  "enabled": true,
  "title": "Сервис-деск",
  "portalUrl": "https://jira.company/servicedesk/customer/portal/1",
  "apiBaseUrl": "https://jira.company",
  "serviceDeskId": "1",
  "requestTypeId": "10",
  "feedUrl": "\\\\server\\share\\desktop-news.json",
  "feedPollSeconds": 300
}
```

`serviceDeskId` и `requestTypeId` — числа из адреса создания заявки на портале: `.../portal/1/create/10`. Если API не задан, кнопка «Заявка» открывает `portalUrl` в браузере и копирует текст в буфер.

Пока сеть недоступна, заявка остаётся в `%LOCALAPPDATA%\DesktopFailover\outbox.json` и уходит сама, когда сетевой рабочий стол снова доступен.

Лента новостей — JSON по адресу `feedUrl`. Это может быть файл на том же файловом сервере или страница `https://...`. Образец: `news.example.json`. Поле `kind` равно `news` или `maintenance`. При первом запуске всплывают только технические работы, чтобы старые новости не засыпали уведомлениями. Счётчик на кнопке «Новости» показывает всё, что пользователь ещё не открывал. Если сервер недоступен, показывается последняя сохранённая копия.

## Проверка

Посмотреть, что программа сделает, не меняя рабочий стол:

```bat
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "%LOCALAPPDATA%\DesktopFailover\DesktopFailover.ps1" -Preview
```

Текущий режим, пути и конец журнала:

```bat
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "%LOCALAPPDATA%\DesktopFailover\DesktopFailover.ps1" -Status
```

Журнал: `%LOCALAPPDATA%\DesktopFailover\desktop-failover.log`.

Чтобы увидеть переключение, отключите доступ к шаре (или укажите в конфиге несуществующий путь и подождите две проверки, около 30 секунд). Проводник на короткое время перезапустится, и на рабочем столе останутся скопированные ярлыки. После возврата шары рабочий стол снова станет сетевым.

## Когда происходит переключение

По умолчанию `probeMode` равен `share`: программа смотрит, открывается ли сама папка рабочего стола. Если интернет пропал и из-за этого папка больше не открывается, рабочий стол переключается на локальный. Если внешние сайты недоступны, а папка на файловом сервере по-прежнему открывается, рабочий стол остаётся сетевым: ярлыки на месте, переключать их не нужно.

| probeMode | Когда включается локальный рабочий стол |
| --- | --- |
| `share` | Сетевая папка не открывается. Это значение по умолчанию. |
| `internet` | Не открывается ни один адрес из `internetProbes`. |
| `shareOrInternet` | Не открывается папка или интернет. |
| `shareAndInternet` | Не открываются и папка, и интернет. |

Один сбой не переключает рабочий стол. Нужны две неудачные проверки подряд и две успешные для возврата (`failureThreshold`, `recoveryThreshold`). Интервал проверки — `pollSeconds`, по умолчанию 15 секунд.

Пока папка доступна, копия обновляется не чаще чем раз в `syncIntervalSeconds` (60 секунд). Копируются файлы и вложенные папки не тяжелее `maxFileBytes` (50 МБ). Временные файлы (`*.tmp`, `~$*`, `thumbs.db`) не копируются. Файлы, которые есть только в локальной копии, не удаляются.

`syncBackOnRecovery` по умолчанию выключен: общий рабочий стол не получает обратно то, что пользователь создал локально во время обрыва. Для личного перенаправленного стола можно поставить `true`.

Проверка интернета идёт через системный прокси обычным HTTP-запросом. Адреса задаются в `internetProbes`.

## Удаление

Запустите `Uninstall.bat` в папке программы или в исходной папке.

Автозагрузка и задача планировщика удаляются. Если сеть в этот момент есть, рабочий стол возвращается на сетевой путь. Если сети нет, остаётся локальный, чтобы ярлыки не пропали снова. Папка программы и локальная копия не удаляются.

## Ограничения

Групповая политика может вернуть сетевой путь при следующем обновлении политики. Пока папка недоступна, программа записывает локальный путь снова. Когда папка доступна, программа сама возвращает сетевой путь.

Копия появляется только после того, как папка хотя бы раз успешно открылась при работающей программе. До первой синхронизации локальный стол пустой.

Если Windows и так показывает папку из автономных файлов (Offline Files), программа считает её доступной и не переключает стол.

При переключении перезапускается Проводник, чтобы ярлыки обновились сразу. Открытые окна Проводника при этом закрываются. Пауза между такими перезапусками — `explorerRestartCooldownSeconds` (120 секунд).

Программу ставят каждому пользователю: у каждого своя локальная копия, источник один.
